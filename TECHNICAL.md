# Техническая справка CampusLens

## 1. Конвейер обработки

```
Название вуза
   │
   ▼
[1] Поиск вуза ─ Wikidata wbsearchentities (ru, en) → wbgetentities
   │             фильтр «это вуз» (P31 или описание); при опечатке — поиск Википедии с подсказкой
   ▼
[2] Сбор кандидатов (параллельно, у каждого источника свой таймаут)
   │   • Wikidata P18 — главное фото вуза
   │   • Commons: категория вуза (P373) + до 14 подкатегорий
   │   • Commons: геопоиск ≤ 800 м от координат кампуса (P625)
   │   • Официальный сайт (P856) — только og:image / twitter:image
   │   • Город (P131 → город): P18 и геопоиск ≤ 1,5 км от центра
   ▼
[3] Проверка ─ объединение одинаковых файлов → фильтры → оценка достоверности
   │             → загрузка превью (до 90 шт.) → размеры и хеши
   ▼
[4] Дедупликация ─ SHA-1 (точные копии) + dHash 64 бит, расстояние Хэмминга ≤ 6
   ▼
[5] AI-анализ (если задан ключ) + категоризация
   ▼
[6] Профиль ─ до 12 фото «Проверено/Вероятно» на категорию; «Не подтверждено» скрыто
```

Бюджет времени — 26 секунд на всё (настраивается `TOTAL_DEADLINE_S`). Этапы, которые не успели, пропускаются, и интерфейс об этом сообщает. Этапы транслируются в браузер через Server-Sent Events по мере выполнения: прогресс на экране отражает реальную работу сервера.

## 2. Внешние сервисы и API

| Сервис | Для чего | Ключ | Условия |
|---|---|---|---|
| Wikidata API (`wbsearchentities`, `wbgetentities`) | Поиск вуза, координаты, сайт, категория Commons, город, страна | не нужен | Данные CC0; обязателен User-Agent с контактом |
| Wikipedia API (`list=search`, `pageprops`) | Поиск при опечатках, подсказка «Возможно, вы имели в виду» | не нужен | CC BY-SA |
| Wikimedia Commons API (`categorymembers`, `geosearch`, `imageinfo` + `extmetadata`) | Фото, автор, лицензия, геометка, дата, SHA-1, категории | не нужен | У каждого файла своя свободная лицензия, показываем её и автора |
| Официальный сайт вуза | og:image — картинка, которую сайт сам отдаёт для превью ссылок | не нужен | Файл не сохраняется, показывается как превью со ссылкой и пометкой «© правообладатель» |
| Google Gemini API (`generateContent`), модель из `GEMINI_MODEL` | Необязательный AI-анализ содержимого фото | `GEMINI_API_KEY` | Бесплатный уровень с лимитами — актуальные условия смотрите в Google AI Studio |
| OpenStreetMap | Ссылка «Кампус на карте» | не нужен | Только ссылка |

## 4. Методы проверки

### 4.1. Фильтры (кандидат исключается)
- тип файла не JPEG/PNG/WebP (SVG-логотипы, PDF, видео);
- нет свободной лицензии (для Commons);
- меньше 500×300 px, нетипичные пропорции (шире 5:1 или уже 1:4);
- в названии файла есть признаки логотипа, герба, карты, схемы, диплома, портрета, скриншота; в категориях Commons — «Logos», «Maps of» и т. п.;
- фото персоналий (категории «People of», «Alumni of»);
- превью с официального сайта не открылось или меньше 400 px.

### 4.2. Показатель достоверности
Показатель складывается из сигналов. Каждый сигнал с его весом показывается в карточке фото в блоке «Почему такой показатель».

| Сигнал | Вес |
|---|---|
| Главное фото вуза в Wikidata (P18) | +0,50 |
| Официальный сайт (адрес из Wikidata, а не из поисковика) | +0,50 |
| Файл в категории вуза на Commons | +0,40 |
| Файл в подкатегории вуза на Commons | +0,40 |
| Файл найден только геопоиском рядом с кампусом | +0,10 |
| Главное фото города в Wikidata / фото из центра города | +0,60 / +0,35 |
| Файл пришёл из нескольких независимых выборок | +0,05 |
| Геометка ≤ 300 м / ≤ 1 км / ≤ 3 км от кампуса | +0,25 / +0,18 / +0,08 |
| Геометка дальше 15 км от кампуса | −0,35 |
| Название вуза (полное, аббревиатура или ≥ 2 отличительных слова) в названии, описании или категориях файла | +0,20 |
| Только близость по карте, вуз не упомянут | −0,05 |
| Свободная лицензия | +0,05 |
| Снимок не старше 8 лет / старше 15 лет | +0,05 / −0,08 |
| AI: на фото университетская среда / не относится к вузу / не фото | +0,15 / −0,45 / −0,50 |

Итог ограничен диапазоном 2–99 %. Статусы: **Проверено** от 75 %, **Вероятно** от 50 %, **Не подтверждено** ниже 50 % (скрыто по умолчанию, можно показать переключателем).

Отличительные слова — это слова из названий и алиасов вуза за вычетом общих («университет», «государственный», «national», «of» и т. п.) и названия города. Поэтому фото «Astana University building» не засчитывается как упоминание Nazarbayev University.

Показатель — эвристическая оценка того, насколько надёжно доказана принадлежность, а не вероятность, откалиброванная на размеченной выборке. Так он и описан в интерфейсе.

### 4.3. Что делает AI, а что нет
Модель получает до 30 уменьшенных превью (384 px) одним запросом и для каждого отвечает в JSON: фото это или графика, какая категория, похоже ли на университетскую (или городскую) среду, и короткое описание. **Модель не определяет, какой именно это вуз:** принадлежность доказывают происхождение файла, геометка и текст. Если AI не ответил за отведённое время, профиль строится по метаданным, и пользователь видит предупреждение.

### 4.4. Категоризация
Шесть категорий: Кампус, Учебные пространства, Общежития, Библиотека, Студенческая жизнь, Город. Сначала ищутся многоязычные ключевые слова (русский, казахский, английский, немецкий, французский, испанский) с весами: название подкатегории ×3, имя файла ×2, категории Commons ×1,5, описание ×1. При равенстве выигрывает более конкретная категория. AI-категория используется, если ключевых слов нет, если они слабые или если по метаданным получилась общая категория «Кампус». «Город» присваивается только фото из городских выборок или по решению AI.

### 4.5. Дедупликация
1. Одинаковое имя файла из разных выборок — один кандидат с несколькими источниками.
2. Одинаковый SHA-1 (Commons отдаёт его в API) — точная копия.
3. dHash: превью переводится в оттенки серого 9×8, сравниваются соседние пиксели, получается 64 бита. Расстояние Хэмминга ≤ 6 означает визуальный дубликат (пересжатие, небольшая обрезка, серия кадров с одной точки). Остаётся копия с более высоким показателем, у неё отображается число скрытых копий.

## 5. Устойчивость
- У каждого источника свой таймаут; ошибка одного источника не ломает профиль, а попадает в предупреждения и таблицу «Как собран этот профиль».
- Один повтор при 429/5xx, ограничение параллельности (12 запросов), ограничение размера скачиваемых файлов.
- Нет вуза: ответ 404 с подсказкой из поиска Википедии. Wikidata недоступна: ответ 503 с понятным текстом.
- Кэш готовых профилей в памяти на 6 часов. Повторный запрос помечается «из кэша», а время первоначальной сборки видно в подсказке.

## 6. Данные
Сервис не хранит фотографии и не использует заранее подготовленных подборок: при каждом новом запросе всё собирается из открытых API. В памяти процесса живут только кэш готовых ответов и нормализованные запросы. Ключи передаются только через переменные окружения.

## 7. API сервиса

| Метод | Описание |
|---|---|
| `GET /api/profile?q=<название или QID>` | Готовый профиль в JSON |
| `GET /api/profile/stream?q=...` | SSE: события `stage`, затем `result` или `fail` |
| `GET /api/suggest?q=...` | До 6 подсказок вузов |
| `GET /api/health` | Проверка живости и признак включённого AI |

Основные поля профиля: `university`, `alternatives`, `categories`, `photos[]` (`thumb`, `category`, `status`, `confidence`, `reasons[]`, `source`, `license`, `author`), `hidden[]`, `stats`, `sources[]`, `warnings[]`, `timing`.
