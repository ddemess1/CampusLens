    Как мы проверяем фото

    От названия вуза до подтверждённого профиля — без ручного подбора снимков, каждый шаг объясним.

    01

    Поиск вуза

    Вуз ищется в Wikidata с учётом опечаток — через поиск Википедии — и неоднозначностей: если найдено похожее, сервис спрашивает «Не тот вуз?».

    02

    Сбор кандидатов

    Параллельно опрашиваются Wikidata, категория и подкатегории вуза на Wikimedia Commons, геопоиск Commons по координатам кампуса, официальный сайт вуза и центр города.

    03

    Фильтры

    Отсеиваются логотипы, карты, документы, портреты, маленькие файлы и файлы без свободной лицензии — в профиль попадают только настоящие фото места.

    04

    Показатель достоверности

    Складывается из объяснимых сигналов: происхождение файла, геометка, упоминание вуза в названии и категориях, лицензия, свежесть снимка и, по желанию, AI-анализ содержимого.

    05

    Дедупликация

    Точные копии убираются по SHA-1, визуально похожие кадры — по перцептивному хешу dHash.

    06

    Категории

    Фото раскладываются по шести категориям: кампус, учебные пространства, общежития, библиотека, студенческая жизнь, город.

    07

    Профиль

    «Проверено» и «Вероятно» видны сразу, «Не подтверждено» скрыто по умолчанию — но его можно показать одним переключателем.

    Собираем профиль 0,0 с
    1. Находим вуз
    2. Ищем фото в источниках
    3. Проверяем принадлежность
    4. Убираем дубликаты
    5. Распределяем по категориям

    Как собран этот профиль

    Почему такой показатель

      Фото берутся автоматически из Wikidata и Wikimedia Commons (открытые лицензии, авторы указаны) и с официального сайта вуза (только превью со ссылкой). Работает для университетов, у которых есть запись в Wikidata; для вузов без фото на Commons профиль будет неполным — сервис так и напишет.
