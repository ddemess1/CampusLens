# CampusLens

AI-сервис, который по названию университета примерно за 30 секунд собирает проверенный визуальный профиль: кампус, учебные пространства, общежития, библиотеку, студенческую жизнь и город. У каждого фото указаны источник, лицензия, статус проверки и показатель достоверности с объяснением.

Кейс LOCUS №1 (код участия LOCUSCASE1).

- **Сайт:** https://campuslens-qzce.onrender.com (вход не требуется)
- **Демо-видео:** https://drive.google.com/file/d/1VxuBo8teWyWQBAuKtIVj3tTGXOtq79NO/view?usp=sharing

## Задача
Абитуриент видит рекламные страницы вузов, а настоящие фото кампуса, общежитий, аудиторий и города разбросаны по разным сайтам, дублируются, устаревают или относятся к другому месту. Нужен сервис, который по одному названию быстро собирает проверенные фото, раскладывает их по категориям и показывает, откуда взят каждый снимок.

## Решение
1. **Название.** Вуз ищется в Wikidata с учётом опечаток (поиск Википедии) и неоднозначностей (кнопки «Не тот вуз?»).
2. **Поиск.** Параллельно опрашиваются Wikidata, категория и подкатегории вуза на Wikimedia Commons, геопоиск Commons у координат кампуса, официальный сайт вуза и центр города.
3. **Проверка.** Отсеиваются логотипы, карты, документы, портреты, маленькие файлы и файлы без лицензии. Показатель достоверности складывается из объяснимых сигналов: происхождение, геометка, упоминание вуза, лицензия, свежесть и (по желанию) AI-анализ изображения.
4. **Дедупликация и категории.** Копии убираются по SHA-1 и перцептивному хешу dHash, фото раскладываются по шести категориям.
5. **Профиль.** Фото со статусом «Проверено» и «Вероятно» видны сразу, «Не подтверждено» скрыты, но их можно показать. Если в категории нет проверенных фото, сервис пишет об этом прямо и ничего не подставляет.

Дополнительно: расстояние от кампуса до центра города, ссылки на сайт, Википедию, Wikidata и карту, таблица «Как собран этот профиль» со статусом каждого источника и временем этапов.

## Стек
- Backend: Python 3.12, FastAPI, Uvicorn, httpx, Pillow
- Frontend: HTML, CSS, JavaScript без фреймворков; этапы приходят через Server-Sent Events
- AI (необязательно): Google Gemini API для анализа содержимого фото
- Данные: Wikidata, Wikipedia, Wikimedia Commons, официальные сайты вузов
- Деплой: Docker (Render или Hugging Face Spaces)

## Архитектура
```
Браузер ──SSE──▶ FastAPI (app/main.py)
                    │
                    ▼
              pipeline.py ──▶ resolver.py ──▶ Wikidata / Wikipedia
                    │
                    ├──▶ sources/commons.py ──▶ Wikimedia Commons
                    ├──▶ sources/official.py ─▶ официальный сайт вуза
                    ├──▶ verify.py      (фильтры, показатель достоверности)
                    ├──▶ dedup.py       (SHA-1, dHash)
                    ├──▶ vision.py      (Gemini, необязательно)
                    └──▶ categorize.py  (6 категорий)
```

| Файл | Назначение |
|---|---|
| `app/main.py` | HTTP API, SSE-поток, раздача фронтенда |
| `app/pipeline.py` | Оркестрация этапов, бюджет времени, кэш |
| `app/resolver.py` | Поиск вуза, город, страна, расстояние до центра |
| `app/sources/commons.py` | Категории, подкатегории, геопоиск Commons |
| `app/sources/official.py` | Превью с официального сайта |
| `app/verify.py` | Фильтры и показатель достоверности |
| `app/dedup.py` | Дедупликация |
| `app/vision.py` | AI-анализ изображений |
| `app/categorize.py` | Категории |
| `static/` | Интерфейс |
| `tests/` | Тесты на подставных ответах API, без сети |

## Запуск локально
```bash
git clone https://github.com/ВАШ-АККАУНТ/campuslens.git
cd campuslens
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # по желанию впишите GEMINI_API_KEY и свой email
uvicorn app.main:app --reload
```
Откройте http://127.0.0.1:8000.

Переменные из `.env` в shell нужно экспортировать (`set -a; source .env; set +a`) или задать в панели хостинга.

Тесты (сеть не нужна):
```bash
python -m unittest discover -s tests -t . -v
```

Через Docker:
```bash
docker build -t campuslens .
docker run -p 7860:7860 -e GEMINI_API_KEY=... campuslens
```

## Деплой
**Render.** New → Web Service → подключить репозиторий → Runtime: Docker → в Environment добавить `GEMINI_API_KEY` и `USER_AGENT`. Бесплатный сервис засыпает после простоя, и первый запрос может ждать около минуты. Поэтому перед проверкой жюри и перед защитой откройте сайт заранее или настройте регулярный запрос к `/api/health` (например, через cron-job.org).

**Hugging Face Spaces.** Create Space → SDK: Docker → загрузить файлы репозитория → в Settings → Variables and secrets добавить `GEMINI_API_KEY`. Порт 7860 уже указан в Dockerfile.

## Тестовый сценарий
1. Открыть сайт, ввести «Nazarbayev University», нажать «Собрать профиль».
2. Наблюдать реальные этапы и таймер. Сервер ограничен бюджетом 26 секунд; фактическое время видно в карточке «Готово за».
3. Переключать категории, открыть любое фото и прочитать «Почему такой показатель».
4. Включить «Показать непроверенные» и посмотреть, что сервис отсеял.
5. Ввести любой другой вуз, например «Satbayev University», «Politecnico di Milano», «Новосибирский государственный университет».
6. Ввести название с ошибкой или несуществующий вуз («Хогвартс»): сервис попробует найти вуз через поиск Википедии, покажет подсказку «Возможно, вы имели в виду» или понятное сообщение «не найдено».
7. Открыть «Как собран этот профиль»: статусы источников, отсеянные файлы, дубликаты, время этапов.

## AI и внешние API
- **Google Gemini** (`generateContent`, модель задаётся `GEMINI_MODEL`): определяет, фото ли это, что на нём и похоже ли на университетскую среду. Какой именно это вуз, модель не определяет. Без ключа сервис работает по метаданным и прямо сообщает об этом в интерфейсе.
- **Wikidata / Wikipedia / Commons API**: поиск и метаданные, ключи не нужны.

## Готовые компоненты и инструменты
- Библиотеки FastAPI, Uvicorn, httpx, Pillow (open source).
- Шрифты Unbounded и Golos Text (Google Fonts, SIL Open Font License).
- Заранее подготовленной инфраструктуры и ручного подбора фото нет: каждый профиль собирается автоматически в момент запроса.

## Ограничения
- Работает для вузов, у которых есть запись в Wikidata. Если у вуза мало фото на Commons или нет координат, профиль будет неполным, и сервис об этом предупредит.
- Фото общежитий и студенческой жизни на Commons встречаются реже, поэтому эти категории часто пустые. Сервис не заполняет их чужими снимками.
- Превью с официального сайта может быть рекламным или стоковым изображением самого вуза. Поэтому ему не присваивается статус «Проверено» без дополнительных сигналов.
- Показатель достоверности — объяснимая эвристика, а не откалиброванная вероятность.
- Время зависит от скорости внешних API; при медленном ответе часть этапов пропускается, о чём сообщается.
- Кэш хранится в памяти одного процесса и сбрасывается при перезапуске.

## Развитие
Сравнение двух вузов, климат и транспорт (Open-Meteo, OSM), дополнительные открытые источники (Openverse, Flickr CC) с обязательной AI-проверкой, модель CLIP для категорий без внешнего API, постоянный кэш (Redis).
